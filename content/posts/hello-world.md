## 为什么选择 Hugo？

Hugo 是当前最快的静态网站生成器，用 Go 语言编写。它能在**毫秒级**完成全站构建，非常适合个人博客。

## 核心优势

- ⚡ **极速构建** — 几千篇文章也能秒级生成
- 📝 **Markdown 写作** — 纯文本写作，专注内容
- 🎨 **丰富主题** — 社区有数百个免费主题
- 🚀 **一键部署** — 生成纯静态文件，丢到 Nginx 即可
- 🔒 **零安全风险** — 没有数据库、没有后端代码

## 写作流程

```bash
# 1. 创建新文章
hugo new content posts/my-post.md

# 2. 写内容（Markdown）

# 3. 本地预览
hugo server -D

# 4. 生成静态文件
hugo

# 5. 部署到服务器
./deploy.sh
```
